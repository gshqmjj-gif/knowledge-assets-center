- **💻 硬件配置规格**: `硬件要求: 推荐 8GB+ 内存，支持 Apple Silicon / NVIDIA GPU 加速 / 运行环境: FFmpeg 6.0+ + Node.js 18+ + Python 3.10+`
- **🌐 运行环境与依赖栈**: `硬件要求: 推荐 8GB+ 内存，支持 Apple Silicon / NVIDIA GPU 加速 + 运行环境: FFmpeg 6.0+ + Node.js 18+ + Python 3.10+`
- **🔒 本地化与隐私能力**: 本地化支持: 🟢 100% 本地流转 (视频切片、音频转录与字幕合成全程在本地磁盘完成，隐私严守)
- **⚡ 同类对比核心优势**:
  - 【全自动视频工作流】原始素材进、高光成片出，彻底告别繁琐手动拖拽时间线。
  - 【声画联合分析】基于 Whisper 逐字稿与画面关键帧联合锚定高光，对齐精确至毫秒级。
  - 【工业工程文件直出】支持导出 Premiere / Final Cut Pro 工程文件，方便进一步微调。
- **⚠️ 劣势、边界与避坑踩坑要点**:
  - 【长素材分段输入】建议单次处理单集 30 分钟以内素材，超长素材宜按章节分段传入避免内存过载。
