### 1. 方案实体: text-to-cad：一句话生成能加工
- **🎯 核心功能与定位**: 核心解决痛点: 一句话生成能加工的 3D 零件；装上之后你的 AI 能多做什么: 一句话生成能加工的 3D 零件，显著突破传统工作流瓶颈。
- **💻 硬件配置规格**: `硬件要求: 普通工作站或轻薄本即可无痛运行 / 运行环境: Python 3.9+ + OpenSCAD / FreeCAD CLI 工业引擎`
- **🌐 运行环境与依赖栈**: `硬件要求: 普通工作站或轻薄本即可无痛运行 + 运行环境: Python 3.9+ + OpenSCAD / FreeCAD CLI 工业引擎`
- **🔒 本地化与隐私能力**: 本地化支持: 🟢 100% 本地生成与导出标准工业文件 (离线即用，完全保护商业工业构件机密)
- **⚡ 同类对比核心优势**:
  - 【工业级可用格式】直接输出标准 STEP / STL / 3MF，而非不可加工的游戏低模网格。
  - 【可制造性检查】自动验证壁厚、装配干涉与切削物理可行性，并自动出具带尺寸的工程图。
  - 【打样闭环】支持直接连通 3D 打印、钣金冲压与 CNC 代工服务一键打样下单。
- **⚠️ 劣势、边界与避坑踩坑要点**:
  - 【复杂曲面边界】当前最擅长规则机械零件与参数化装配体；极度复杂的自由流体有机曲面仍需手工建模配合。
- **🛠️ 上手验证常用指令**:
  ```bash
  git clone https://github.com/earthtojake/text-to-cad
  ```

### 2. 方案实体: XPlant2.0
- **🎯 核心功能与定位**: 面向山地景观规划与参数化种植设计的 Rhino／Grasshopper 工具平台，将地形分析、现状评价、专项设计和成果输出整合为可连接、可复用的组件体系。
- **💻 硬件配置规格**: `常规设计工作站 (建议 16G 内存 + 独立显卡)`
- **🌐 运行环境与依赖栈**: `Rhino / Grasshopper 平台 + 空间分析/GIS 插件组件`
- **🔒 本地化与隐私能力**: 🟢 纯本地离线运行 (基于本地 Rhino/Grasshopper 本地计算与离线 Mesh 分析)
- **⚡ 同类对比核心优势**:
  - 【多模态空间数据输入】支持测绘高程点、等高线、地形 Mesh、土地利用及外部模型数据，建立从空间分析到方案生成完整流程。
  - 【全专项功能组件覆盖】覆盖总体规划、山地植物设计、生态修复、海绵雨洪、水库堰塞湖安全、道路游线、建筑设施选址、边坡地质安全、土方竖向等。
  - 【设计依据量化可追溯】把复杂地形转化为量化分析结果，直接驱动分区、选址、路径组织和种植配置，支持多方案迭代。
- **⚠️ 劣势、边界与避坑踩坑要点**:
  - 【当前版本边界】当前处于 DEMO 版本阶段，仍处于持续演进与功能完善中。
